# 天行九歌·秦时明月 - 动漫主题网站

> 以史为镜，可以知兴替。

一个基于 HTML、CSS、JavaScript 技术栈构建的中国古风动漫主题网站，以《天行九歌》和《秦时明月》两部经典 3D 武侠动画为核心内容，融合战国历史文化，为用户呈现一个沉浸式的古风动漫世界。

## 🌟 项目特色

- **双动漫主题**：深度展示《天行九歌》和《秦时明月》两部经典动画
- **历史文化融合**：结合战国七雄、诸子百家等历史元素
- **沉浸式体验**：古风背景音乐、精美视觉设计
- **响应式布局**：适配不同屏幕尺寸的设备
- **交互式轮播**：首页精美的图片轮播展示
- **多媒体内容**：集成 B 站视频、背景音乐等多媒体元素

## 🎯 功能模块

### 主要页面

- **首页 (index.html)** - 项目总览，动漫介绍，图片轮播
- **天行九歌 (tianxingjiuge.html)** - 专题介绍天行九歌动画
- **秦时明月 (qinshimingyue.html)** - 专题介绍秦时明月系列
- **战国七雄 (zhanguoqixiong.html)** - 战国历史背景介绍
- **诸子百家 (zhuzibaijia.html)** - 春秋战国思想流派介绍
- **成王败寇 (end.html)** - 项目结语页面
- **关于我们 (about.html)** - 项目信息和制作团队

### 核心功能

- 🎵 **背景音乐播放** - 《心之逆鳞》、《月光》等主题音乐
- 🖼️ **图片轮播系统** - 自动轮播与手动控制
- 📺 **视频嵌入** - B 站视频无缝集成
- 🎨 **动态背景** - 多层背景图片营造氛围
- 📱 **响应式导航** - 清晰的页面导航系统

## 🛠️ 技术栈

- **前端框架**: 原生 HTML5 + CSS3 + JavaScript
- **样式设计**: 自定义 CSS，古风主题设计
- **交互效果**: 原生 JavaScript 实现轮播、动画等效果
- **多媒体**: HTML5 Audio/Video API
- **字体**: 微软雅黑等中文字体优化

## 🎨 设计理念

项目采用古风设计风格，以深色调为主，配合金色点缀，营造出浓厚的历史氛围。页面布局采用传统的左右分栏设计，既保持了现代网页的易用性，又体现了古典美学的对称之美。

### 色彩搭配

- **主色调**: 深棕色 (#734633)、古铜色 (#834524)
- **辅助色**: 金黄色 (#e3b503)、白色文字
- **背景**: 古风纹理图片，营造历史氛围

### 交互设计

- 平滑的页面过渡动画
- 鼠标悬停效果
- 自动轮播与手动控制结合
- 音乐自动播放（支持用户控制）
